# Project Overview

## NetAssist AI

NetAssist AI is an AI-assisted Network Support and Diagnostic Platform developed during my BSNL internship.

The platform helps users report network-related issues, receive AI-assisted first-level troubleshooting guidance, generate diagnostic reports, and track support tickets.

Administrators can manage users and support tickets, view diagnostic reports, and analyze support data through an administrative dashboard.

## Main Objectives

- Provide a structured platform for reporting network issues.
- Provide AI-assisted troubleshooting guidance.
- Generate diagnostic reports.
- Track support tickets and their status.
- Provide administrative analytics.
- Demonstrate the use of AI in network-support workflows.

## Supported Network Issues

- Slow Internet
- No Internet
- High Ping
- DNS Failure
- Wi-Fi Disconnecting
- Packet Loss
- FTTH Broadband
- Fiber Fault
- ONU Offline
- Router Configuration
- LAN Issues
- Static IP Issues
