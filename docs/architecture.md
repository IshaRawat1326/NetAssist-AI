# System Architecture

## Application Flow

User/Admin
↓
NetAssist AI Web Application
↓
Authentication
↓
Support Ticket Management
↓
AI-Assisted Diagnosis
↓
Diagnostic Report
↓
PDF Generation
↓
Admin Analytics

## Main Components

### Authentication

Provides user login and role-based access for users and administrators.

### Support Ticket Management

Allows users to create, view, and track network-support tickets.

### AI Assistant

Provides first-level troubleshooting guidance for common network issues.

### Diagnostic Reports

Converts AI-assisted diagnosis into structured reports that can be downloaded as PDF documents.

### Administration

Allows administrators to manage users, support tickets, reports, and application activity.

### Analytics

Provides insights into ticket volume, resolution status, common issues, and support activity.
